Privacy Policy

JobCardsTranslation is a personal automation used only by its owner. It accesses only the owner's own Google Drive and Google Sheets to read and update the owner's files. It does not collect data from other users, does not sell or share any data with third parties, and stores OAuth tokens only locally on the owner's computer. Google user data is used solely to perform the automation and is handled in accordance with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.

Política de Privacidade

O JobCardsTranslation é uma automação pessoal usada apenas pelo seu dono. Ele acessa somente o Google Drive e o Google Sheets do próprio dono para ler e atualizar seus arquivos. Não coleta dados de outros usuários, não vende nem compartilha dados com terceiros e guarda os tokens OAuth apenas localmente no computador do dono. Os dados do Google são usados exclusivamente para executar a automação, conforme a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O acesso pode ser revogado a qualquer momento em https://myaccount.google.com/permissions.
